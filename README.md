# 장뇌 보트 분석기

장뇌(C₁₀H₁₆O) 보트 영상에서 등속 구간의 속도 v를 구하고, 정제수 속도 v₀로 나눈 상대속도 v/v₀와 표준곡선으로 세제(LAS) 농도를 추정하는 **브라우저 전용** 웹사이트입니다. 영상은 서버로 올라가지 않고 내 컴퓨터(휴대폰) 안에서만 처리됩니다.

## 사용법 (5줄)

1. **영상 불러오기**: 촬영한 mp4/mov를 고르고, 초당 프레임 수(fps)를 확인합니다. 처음이라면 맨 위 **데모 불러오기**로 체험해 보세요.
2. **축척 설정**: 영상 속 자의 두 눈금을 찍고 실제 길이(mm)를 입력한 뒤, 보트가 지나가는 수로를 사각형으로 감쌉니다.
3. **보트 추적**: **자동 추적 시작**을 누르고 임계값을 조절하세요. 틀린 프레임은 **직접 찍기**로 고칩니다.
4. **속도 계산**: 자동으로 찾은 등속 구간의 속도를 확인하고 종류(정제수/시료/표준용액)를 골라 **기록에 저장**합니다. 정제수는 3번 이상 저장해야 v₀가 정해집니다.
5. **농도 추정**: 표준곡선 점을 넣거나(CSV 가능) 표준용액 기록을 쌓으면 추정 농도, LOD·LOQ, 반복 측정 평균과 RSD가 표에 나오고 CSV로 내보낼 수 있습니다.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소로 올립니다 (기본 브랜치 `main`).
2. 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꿉니다.
3. `main` 에 push 하면 `.github/workflows/deploy.yml` 이 테스트 → 빌드 → 배포를 자동으로 합니다.
4. 주소: `https://<사용자이름>.github.io/<저장소이름>/`

`vite.config.ts` 의 `base: './'` 덕분에 저장소 이름과 상관없이 동작합니다.

## 테스트로 확인하는 것

- 회귀·통계·CSV·표준곡선 역산·LOD/LOQ 공식이 손으로 푼 값과 일치
- **가상 데이터**: 정지 → 가속 → 등속 → 감속 운동에 노이즈를 넣은 합성 데이터에서 등속 구간을 찾고 속도를 **±3% 안**에서 복원 (속도·fps·노이즈를 바꾼 여러 경우 × 10개 난수 시드)
- 정지한 보트, 계속 가속하는 보트는 등속 구간으로 잡지 않음
- 합성 프레임에서 보트 중심을 1화소 안에서 찾음, 300프레임 추적이 1초 안에 끝남
- 실제 mp4/mov 파일(25, 29.97, 60 fps, B-프레임, 90° 회전)에서 fps·프레임 정보 읽기

## 가정 (요구사항에서 정해지지 않아 합리적으로 정한 것)

- **등속 판정**: 각 점에서 시작하는 0.5초 창으로 회귀하고, R² ≥ 0.98 인 창이 연속으로 이어지며 모든 창의 기울기가 그 묶음 평균 기울기의 ±10% 안에 드는 가장 긴 묶음을 고릅니다. 구간은 첫 창의 시작부터 마지막 창의 끝까지이고, v는 그 구간 전체를 다시 회귀한 기울기의 크기(방향 무관)입니다. 구간이 1.5초보다 짧으면 경고합니다.
- **위치**: 보트의 2차원 위치를 처음→마지막 추적 점 방향으로 투영한 거리(mm)이며 첫 점이 0 mm입니다.
- **보트 찾기**: 수로 영역을 최대 640×400 화소로 줄여 회색조로 바꾸고, 영상 전체에서 고르게 뽑은 25장의 화소별 중앙값을 배경으로 씁니다. 배경과의 밝기 차이가 임계값 이상인 화소 중 가장 큰 연결 덩어리의 중심을 보트 위치로 봅니다. 첫 임계값은 오츠 방법으로 자동 추천합니다. OpenCV.js는 쓰지 않았습니다.
- **프레임 읽기**: 브라우저가 WebCodecs를 지원하고 코덱(H.264, HEVC, VP9, AV1)을 풀 수 있으면 재생 없이 모든 프레임을 직접 풉니다. 안 되면 4배속 재생(일부 프레임은 건너뛸 수 있음), 그다음 프레임별 탐색(느림)으로 넘어갑니다. ‘호환 모드’를 고르면 처음부터 프레임별 탐색을 씁니다. 시간은 영상에 기록된 실제 시각을 씁니다.
- **fps**: MP4/MOV 머리말의 평균 fps를 읽습니다. 읽지 못하면 30으로 두고 직접 입력하게 합니다.
- **v₀ 와 σ₀**: v₀는 ‘정제수’로 저장한 기록(최소 3개)의 v 중앙값입니다. σ₀는 각 정제수 v/v₀의 표본표준편차(n−1)입니다. 정제수 기록이 3개 미만이고 표준곡선에 0 mg/L 점이 3개 이상 있으면 그 점들로 σ₀를 구합니다. 정제수 기록은 0 mg/L 표준곡선 점으로도 들어갑니다.
- **S**: 사용자가 고른 농도 구간(기본: 가장 낮은 농도부터 네 번째 농도까지)의 점으로 v/v₀ = a + S·c 직선을 맞춘 기울기입니다. LOD = 3σ₀/|S|, LOQ = 10σ₀/|S| 이며 단위는 mg/L입니다.
- **표준곡선**: ‘선형’은 v/v₀ = a + b·c, ‘로그 농도’는 v/v₀ = a + b·log₁₀c 를 최소제곱으로 맞춥니다. 로그에서는 0 mg/L 점을 뺍니다. 역산한 농도가 표준곡선에 쓴 최저~최고 농도 밖이면 ‘범위 밖’, LOD보다 낮으면 ‘감지한계 미만’, LOQ보다 낮으면 ‘정량한계 미만(참고값)’으로 표시합니다.
- **반복 측정**: 같은 종류·같은 이름(표준용액은 같은 농도까지)의 기록을 한 시료로 묶습니다. 추정 농도는 평균 v/v₀로 계산하고, RSD는 표본표준편차/평균×100 입니다.
- **저장**: 측정 기록과 표준곡선은 이 브라우저의 localStorage에만 저장됩니다. 다른 기기와 공유하려면 CSV로 내보내세요.
- **데모 데이터**: v/v₀ ≈ 1/(1 + c/4) 관계와 정제수 v₀ ≈ 25 mm/s, 약 ±1.5% 오차를 가정해 만든 가상 값이며 실제 실험값이 아닙니다. 데모 영상은 브라우저에서 그리는 합성 영상(보트 18.4 mm/s, 2 px/mm)입니다.
- **영상 형식**: 아이폰 HEVC(.mov) 영상은 브라우저에 따라 열리지 않을 수 있어, 카메라 포맷을 ‘높은 호환성’(H.264)으로 찍기를 권장합니다. 회전 정보가 있는 세로 영상도 지원합니다.
